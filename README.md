# AstrBot 生图工作室

当前版本：0.3.0。已实现双设置区域和 API 工作流选择、导入、映射及动态参数。双设置通过本地模拟测试及真实 ComfyUI 只读校验；多例图功能通过模拟模型与前端测试，尚未完成 NAS 安装验收，也未调用 AstrBot 配置的 LLM。此前内置流程已完成一张实际出图。详情见 [实际出图测试](docs/smoke-test-20261029.md)。

项目维护文档：[开发文档](DEVELOPMENT.md) · [更新日志](CHANGELOG.md) · [开发约定](AGENTS.md)。后续每次更新同步记录并创建本地提交，默认由用户推送和安装。

## 首版范围

以本机 ComfyUI 为唯一生图后端，支持选择 API 工作流并保留内置 Anima，参考 DSH 生图工作室的交互思路和表情包管理器的 AstrBot 页面接入方式。当前不实现 65535 或远程 OpenAI 图片接口。

- `/画图 <画面描述>` 手动调用，`image_generate` 供对话模型自主调用。
- 画像绑定 AstrBot 实际人格 ID，支持多张例图、统一分析后的外观/画风/服饰与神态习惯，旧单图画像自动兼容。
- 看图 LLM 从例图和人格提取档案，提示词 LLM 结合人格及当前消息生成英文视觉描述，固定外观与画风由插件组合。
- 管理网页分为“人格画像设置”和“ComfyUI 设置”，另保留试生成、生成记录。画像解析模型、提示词模型与规则统一配置，每个人格独立保存参考图和档案。
- 所有账号、会话、人格和网页共用一个任务，完成后全局冷却默认 300 秒，可配置。
- 持久化任务 ID、图片与冷却；结果不明时保留占用，恢复时查询原任务，不自动重复提交。

LLM 使用 AstrBot 已配置的提供商；其推理费用取决于所选服务。本插件不新增模型账户或 API Key。

## 工作流

“ComfyUI 设置”支持：检测当前填写地址 → 获取已保存 JSON 列表 → 选择并加载 API 工作流 → 确认正面/负面提示词、参考图、种子、重绘强度和图片输出映射 → 编辑需要覆盖的参数 → 校验保存。编辑器格式会提示导出 API 版本，也可直接导入 API JSON；导入时选中的编辑器文件作为来源标记，不做自动转换。

远程文件放在 **ComfyUI/user/default/workflows/** 内，建议 API 文件放入 `api/` 子目录；不读取任意磁盘目录。当前环境的文件为 `G:\ComfyUI-aki\ComfyUI-aki-v3.2\ComfyUI\user\default\workflows\api\Anima+本地简易反推流.json`，在列表选择 `api/Anima+本地简易反推流.json`。

参数类型、模型选项及范围来自 `/object_info`；按节点折叠，仅显示所选输出依赖链中的可编辑字面量。勾选参数后才覆盖默认值。连线保持不变，只有明确映射的输入会替换连线。图片输出目前支持一个 SaveImage/PreviewImage 节点；仅提交其依赖链，避免运行无关输出。

映射了参考图时，所有人格共用此流程，但每次任务从当前人格的全部例图中随机选一张上传；未映射时不上传。人格中的旧“生成方式”仅用于内置 Anima，自定义流程的模式开关需在工作流参数中设置；“重绘强度”只有显式映射后才注入。

### 内置 Anima（兼容原配置）

原始工作流及环境调查见 [ComfyUI 工作流记录](docs/comfyui-research.md)。原始 JSON 与本机配置均未修改。

新的 [API 工作流示例](workflows/anima_api.json) 来自原流程的模型与采样链；运行时由 `workflow.py` 填入参数：

- UNet：`anima_baseV10.safetensors`。
- 文本编码器：`qwen_3_06b_base.safetensors`，类型 `qwen_image`。
- VAE：`qwen_image_vae.safetensors`。
- 采样：36 步、CFG 4、`euler`、`simple`，每次新种子，单张输出。
- 默认 888 × 1184，约为原流程的 1 MP、3:4 比例，尺寸可调。
- 正面文本直接进入节点 218，绕过 PixAI、TIPO 和前端透传节点，避免重复扩写。

两种模式可按人格选择：

| 模式 | 参考图作用 |
| --- | --- |
| 文生图（默认） | 例图由看图模型解析为档案，Anima 接收文字特征，动作与构图更自由 |
| 参考图重绘 | 随机选择一张人格例图上传到 ComfyUI，居中裁剪至目标尺寸后经 VAE 编码，默认降噪 0.55；可能保留原图姿势与构图 |

当前工作流没有专门锁定人物身份的图像条件节点。两种方式都需用实际画像检查角色和画风一致性，不能仅凭接口接通判断达标。

## 多例图使用方式

- 每个人格可上传任意张数的例图，支持一次多选、多次追加及逐张移出；单张仍限 20 MB、2400 万像素，实际总量受磁盘及服务请求限制。
- 统一分析会遍历全部例图，每批最多 4 张，结合人格和上批综合结果累积汇总；不会随机抽样或只分析第一张。需使用支持多图输入的视觉模型，每批调用最长等待 120 秒，图片越多，耗时和模型调用费用越多。
- 为控制单次视觉请求体积，使用最长边 1536 像素、JPEG 质量 85 的临时副本；原图保留，图生图仍使用原图。分析以后台任务执行，页面每 5 秒刷新进度；仅保留最近一次分析的进度与结果。
- 分析失败或重载中断时不覆盖已保存档案、不自动重试。编辑中的档案未变化时完成结果自动填入；否则保留编辑内容，检查结果后手动应用并保存。
- 随机参考图在生成任务受理时选定并保存到任务快照，记录中可查文件名。恢复原任务不会重新随机，也不会重新提交。自定义工作流仍只接收一张图，不需要为此增加多个 LoadImage。
- “移出例图”修改当前列表，保存后生效；磁盘文件暂不物理删除，以免破坏已受理任务的快照。移出或追加后请重新分析，统一档案再保存。

## 安装后设置步骤

以下步骤在下一阶段完成 NAS 部署后使用：

1. 打开 AstrBot 插件页面/插件详情中的“生图工作室”。沿用 Dashboard 登录，不增加独立端口。
2. 在“ComfyUI 设置”填写 NAS 可访问的地址，保存设置，再点击“检测连接并获取工作流”。预填 `http://192.168.0.203:8188`，需要 NAS 实际可达。
3. 选择 `api/Anima+本地简易反推流.json`，点击加载。若是编辑器格式，导出/导入 API JSON。检查自动建议的提示词、种子、参考图和输出映射，校验并保存。
4. 展开相关节点，勾选并设置需要覆盖的尺寸、采样、模型或模式参数。自定义流程不会套用旧的内置 Anima 参数；也可切回内置 Anima。
5. 在“人格画像设置”选择共用的画像解析模型与提示词模型并保存。逐个人格选择，多选或分次追加例图，点击“统一分析全部例图与人格”。页面显示后台进度，完成后检查并保存档案；分析中修改了档案或切换人格时，不自动覆盖，需要手动应用结果。人格原文变化后须重新确认。
6. 内置图生图或自定义图有参考图映射时，从该人格的例图列表随机选择一张；没有映射时例图仅用于 LLM 解析档案。自动发图仍需开启对应人格开关，并允许使用 `image_generate` 工具。
7. 在“试生成”输入画面需求，可先预览提示词再实际生成。预览有效 10 分钟，确认生成复用已预览文本；修改画面、画像或配置后预览失效。
8. 生成完成后网页中查看结果；聊天触发则发送到原会话。NapCat/OneBot 的实际发送仍需验证，暂不承诺所有平台适配器都支持后台发送。

上传图片最多 20 MB、2400 万像素。内置 Anima 的尺寸上限仍为 160 万像素；自定义工作流按节点定义校验，管理员需检查尺寸与批量数，不能假设内置尺寸限制仍适用。已有 AstrBot 配置字段保留；自定义工作流、映射和覆盖参数单独保存到插件数据目录的 `workflow.json`。API JSON 限 1 MB、500 个节点。

画像、输出图、历史与任务状态保存在容器 `data/plugin_data/astrbot_plugin_image_studio/`，不混入源码。历史最多显示/保留最近 200 条记录，网页一次显示最近 24 条；生成图片文件目前不自动清理。

## 限流和故障处理

- 手动、自动及网页生图共用限制，模型无法通过参数绕过。忙碌或冷却时拒绝，不排长队。
- 受理前检查 ComfyUI 实时连接（最长等待 5 秒）；连接失败时不调用提示词模型、不创建生图任务或新冷却，直接返回失败。提示词预览同样要求连接可用。
- 自然聊天中的自动工具返回真实状态和表达要求：保持原人格的语气、称呼和交流方式，自然说明暂时无法提供图片并继续对话；不照搬错误原文、任务编号或网络诊断，不切换为系统/客服口吻。失败时不假称已受理或已生成、不本轮反复调用、不承诺自动重试。
- 人格系统提示词保留，插件只追加工具规则，不写固定角色台词。手动 `/画图`、`/生图状态` 和任务后台失败通知仍直接返回状态消息；这些通知不经过聊天 LLM 改写。网页保留排障信息，连接失败返回服务不可用错误。
- 提交前检查 ComfyUI 队列；本机已有任务时不调用提示词 LLM 或继续堆积。检查队列不能阻止用户之后在 ComfyUI 手动提交任务。
- 生图全程占用任务；例图解析和提示词预览也使用同一互斥入口，避免连点模型调用。
- 已受理任务失败后进入冷却；检测到 ComfyUI 已忙、尚未提交的任务不重置冷却。
- 超时、断网或重载不会自动重新提交。使用“查询/恢复原任务”跟踪保存的 ID；兼容通过 client_id 查找丢失提交响应的旧服务任务。
- 结果未知时暂停受理新任务。核查 ComfyUI 队列与历史后，可手动“确认解除未知任务”；队列不为空时禁止解除。
- 图片已生成但发送失败时保留文件，从生成记录下载，不重新生图。发送结果因重载而不明时不自动重复发送。
- 配置与画像变更对后续任务生效，已受理任务使用快照。配置页有并发修改检测。

### 页面入口兼容性修复

AstrBot 4.28.2 的源码仅发现 `pages/<页面名>/index.html`，桥接对象为 `window.AstrBotPluginPage`。初版误用新版文档的 `views/` 和 `AstrBotPluginView`，导致已实现的页面无法被该版本发现。现已改为 `pages/studio/`，并兼容两种桥接名称；页面标题元信息使用 `pages.studio`。

更新插件并重载后，在插件详情中打开“生图工作室”；侧栏未更新时刷新 Dashboard。该修复尚未在 NAS 上完成实际页面验收。

### 更新 ComfyUI 工作流的影响

自定义工作流保存完整 API 图、映射、参数覆盖和文件指纹，不会跟随 ComfyUI 编辑器的未保存内容，也不在每次生成时静默换图。

- ComfyUI 保存新版本后，在插件重新选择并加载，检查映射和参数，再校验保存。相同来源保留原映射；失效输入明确标记，缺失旧覆盖参数提示重新确认。
- 受理前用实时节点定义校验已保存图；节点或模型缺失则拒绝，尚不调用提示词 LLM。ComfyUI 地址改变后要求重新加载并保存工作流。
- 已受理任务持有自己的工作流快照；切换只影响后续任务。旧任务记录没有此字段时继续按内置节点 222 恢复。
- 暂不支持编辑器 JSON 自动转换、子图、远程 API 节点、多图片输出选择和任意自定义字面量。ComfyUI 多用户认证尚未适配。

这份 Anima API 文件的参考设置：正面 `218.text`、负面 `214.text`、种子 `220.seed`、参考图 `398.image`、输出 `222`。默认建议不改变工作流的文生图开关；如要图生图，展开节点 `209 PrimitiveBoolean`，勾选覆盖并将 `value` 设为 false。可将重绘强度映射到 `211.value`，由各人格的强度控制；也可以直接使用工作流原值。请核对实际导出文件，不依赖编号永远不变。
